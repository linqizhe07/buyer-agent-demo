5 · 骨架说明 做了什么、模拟了什么、下一步接哪里

做了

  • 按 MetaMask Agent Wallet 的形状：用户智能账户持钱，agent 一把会话钥匙，一份带 caveats 的授权，随时撤销
  • 连接器目录：CEX / DEX 永续 / DEX 现货 / 预测市场 / RWA / 券商，一个形状
  • 一份策略（float、总敞口、日上限、提币白名单、session、撤销、模式）编译成各家原生限制：链上委托 caveats、CEX key 权限、perp DEX agent key、签名器 allowlist、RWA 发行方转让限制
  • 注资与提回两个判定：session → 金额 → 认识 → 接入 → 撤销 → float → 总敞口 → 日上限 → 余额；撤销后仍可提回

模拟了

  • 轨道是桩：注资是一行流水，不会真的把场所模拟器记上账（demo runner 里的钱包才会）
  • 没有链：EIP-7702 / ERC-7710 / DelegationManager 只是编译表里的文字，没有合约、没有 revoke 交易
  • "已接入"只说明钱包这一侧配好了；席位是否挂载另有标记。Polymarket / Ondo / xStocks 等没有席位
  • RWA 的 KYC 白名单与发行方冻结是发行方的事；这里只写出谁强制
  • Guard / Beast 只是显示；demo runner 仍每笔过卡。签名全部是 ed25519 替身
